# License selection required before public release

No open-source license has been assigned to this repository yet.

A public repository without an explicit license is generally viewable but does not grant broad reuse, modification, or redistribution permissions. Before describing the code as openly licensed, the authors must choose a license and add its complete text.

Common choices include:

- MIT: permissive, short, requires preservation of copyright and license notices.
- BSD-3-Clause: permissive, includes a non-endorsement clause.
- Apache-2.0: permissive, includes an express patent grant and additional notice requirements.

This file is a release blocker, not a license. Do not replace it with an assumed license without author approval. Also verify that every included source file is owned by the authors or is otherwise permitted for redistribution.
